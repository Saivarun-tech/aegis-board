# 🛡️ Aegis Board

Aegis Board is a collaborative work management and productivity platform designed for teams to manage employees, assign work, and collaborate through a shared board.

## 🌐 Live Application

**Production:**  
https://aegis-board-mauve.vercel.app

## ✨ Features

- 🔐 Admin and Employee access
- 👥 Employee management
- 📋 Work assignment and tracking
- 🎨 Interactive collaborative board
- 🤝 Live collaboration
- 🔑 Secure user sessions
- 🗄️ PostgreSQL database

## 🏗️ Tech Stack

### Frontend

- React
- TypeScript
- Vite
- CSS

### Backend

- Python
- FastAPI
- SQLAlchemy
- Alembic
- Argon2

### Database

- PostgreSQL
- Neon
